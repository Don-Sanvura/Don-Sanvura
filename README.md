## Featured Projects

### 1. [Foreman OS](https://github.com/Don-Sanvura/Foreman-OS)
**Multi-business AI agent operating system**  
An actively developed concept for coordinating specialised business agents through a shared control layer and human approval workflow. The design emphasises controlled autonomy, clear permissions, and operator oversight.

**Focus:** AI agents, workflow orchestration, API design, SaaS architecture, human-in-the-loop systems.

### 2. [Weather Prediction System](https://github.com/Don-Sanvura/Weather_Forcasting.github.io)
**Machine learning and predictive modelling**  
A weather prediction project exploring regression and classification tasks using atmospheric observations. The repository documents data preparation, feature engineering, and model development.

**Focus:** Python, Pandas, scikit-learn, Flask, data visualisation.

### 3. [BC WildWatch](https://github.com/Don-Sanvura/WildWatch)
**Campus wildlife hazard reporting concept**  
A project focused on helping a campus community report and monitor wildlife hazards. The project documentation explores reporting workflows, alerts, access control, and analytics.

**Focus:** Web applications, reporting workflows, application architecture, analytics.

### 4. [Sales Forecasting](https://github.com/Don-Sanvura/Sales_Forecasting)
**Predictive analytics for business data**  
A forecasting project using historical sales data, date-based feature engineering, and a linear regression baseline to explore future demand.

**Focus:** Python, Pandas, NumPy, scikit-learn, time-aware model evaluation.

### 5. [Campaign Performance Analysis](https://github.com/Don-Sanvura/Campaign-Performance-Analysis)
**Data analysis for marketing decisions**  
An Excel-based case study comparing campaign messages and channels to identify patterns in sales and new-customer conversion.

**Focus:** Excel, pivot tables, charts, business insights, evidence-based recommendations.

### 6. [Data Visualisation with Python](https://github.com/Don-Sanvura/Data-Visualization-using-Python-master)
**Exploratory data analysis and visual communication**  
A collection of notebooks and examples exploring ways to communicate patterns, distributions, and relationships in data.

**Focus:** Python, Jupyter Notebook, Pandas, Matplotlib, Seaborn.

## How I Approach Projects

- **Understand the problem:** identify the user, goal, constraints, and expected result.
- **Build in manageable steps:** keep the code and project structure understandable.
- **Document decisions:** explain setup, design choices, limitations, and next steps.
- **Improve through testing:** validate key workflows and record known issues instead of overstating readiness.
